# SOA-20261111-08 — Pengeluaran berulang

## Kontrak

Template tersedia melalui `GET/POST /api/v1/recurring-costs`, `GET/PATCH/DELETE
/api/v1/recurring-costs/:id`, `PATCH /api/v1/recurring-costs/:id/status`, dan
`POST /api/v1/recurring-costs/preview`. Occurrence dapat dibaca melalui
`GET /api/v1/recurring-costs/:id/occurrences`.

Occurrence menyimpan `amount_snapshot`, `due_date`, status, dan referensi
`transaction_id` opsional. Template memakai soft delete; pause atau arsip tidak
menghapus occurrence maupun transaksi historis. Preview dan daftar recurring
menampilkan jadwal sebagai rencana, bukan pembayaran bank.

## Kebijakan tanggal dan kategori

Tanggal 29, 30, atau 31 dipertahankan sebagai hari anchor. Jika bulan target
lebih pendek, tanggal diklem ke hari terakhir bulan tersebut. Perhitungan
Februari mengikuti tahun kabisat dan tidak pernah menggeser jadwal ke bulan
berikutnya.

Occurrence hanya dapat diubah ketika masih mendatang, berstatus `planned`, dan
belum memiliki `locked_at`; selain itu API merespons `409`. Penghapusan kategori
yang masih dipakai template recurring aktif juga merespons `409`. Arsipkan atau
jeda template terlebih dahulu.

Mesin eksekusi transaksi belum termasuk milestone ini dan dijadwalkan untuk
23 November.
